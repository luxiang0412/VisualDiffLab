# Reference applications and what was borrowed

No reference screenshots are redistributed in this repository. The apps below were used as interaction and platform-consistency references only; the Visual Diff Lab UI is original. If screenshots are added later, their source URL and license must be recorded here first.

| Reference | What was borrowed | What was deliberately not copied |
|---|---|---|
| [WinUI 3 Gallery](https://github.com/microsoft/WinUI-Gallery) | Fluent control usage, `CommandBar` overflow, `SelectorBar`, `InfoBar`, `ContentDialog`, theme resources, focus behavior | Sample-app navigation shell and card-heavy gallery layout |
| [Microsoft PowerToys](https://github.com/microsoft/PowerToys) | Professional tool settings organization, compact status feedback, honest error/status reporting | Settings-module structure and Fluent glass/backdrop usage |
| [Figma](https://www.figma.com/) (interaction principles) | Canvas-first layout, pointer-anchored zoom, space-drag pan, tool mode feedback | Complex layer panels, multiplayer, property editors |
| [OICAT](https://github.com/MalumaDev/OICAT) | Comparison mode set (side-by-side, wipe/slider, overlay, diff), threshold concept | Its visual identity, workflows, and any implementation details |
| [Image Compare](https://github.com/gimletlove/imagecompare) | Familiar difference/export terminology; viewport split behavior | Code, icons and layout |
| [Windows Photos](https://apps.microsoft.com/detail/9wzdncrfjbh4) | Windows conventions for opening images, fit/100%, basic commands | Photo editing, albums, cloud features |
| [Playwright screenshot assertions](https://playwright.dev/docs/test-snapshots) | Conceptual framing of visual review; **not a runtime dependency or test mechanism** | Browser automation/execution (explicit non-goal) |
